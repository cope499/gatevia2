# Gatevia 2（ローカル版）

本家の Gatevia（最小版）はそのまま残し、別に作っている改良版です。
見た目をカーナビ1に寄せ、フローを通常のナビ式に変えています。
**このフォルダはローカル開発用で、デプロイ対象ではありません。**

## カーナビ1に寄せた点

- 画面構成: 全画面地図 + 上部は単一の検索バー + クイックチップ
  （自宅/レストラン/コンビニ/ショッピング/ガソリンスタンド/駐車場）、
  右下に現在地ボタン、下部タブバー（ナビ / マイルート / 設定）
- 見た目: ダークなガラス質感（半透明ダークパネル + ぼかし + 細い枠線）
- 最小版にあった大きな白い二段パネル（出発地/目的地の常時表示）は廃止し、
  ルート設定は下部シートに格納

## フロー（通常のナビ式）

1. 検索バー・チップ・地図タップで目的地を指定（出発地は現在地が既定）
2. 「ICを選んで検索」→ 乗るICを選ぶ → 降りるICを選ぶ
   - 列挙はサービスの `presentation: 'lazy'` 形式（B3）で受け、
     未計算ペアは選んだ時点で `mode: 'explicit_pair'` で計算する
   - サービスが lazy 形式に未対応の場合は、通常モードの全計算結果を
     入口ICグループに畳んで同じ選択フローに載せる（縮退動作）
3. 「一般道ルート」→ サービスが `surface_candidate` を返せば別枠で表示
   （返さないサービスでは、その旨を明示する）

## 検索

- 地名検索: 自前施設辞書（`facilities.json`、IC/JCT/SA/PA 1,882件）を
  優先し、無ければ Nominatim にフォールバック
  （辞書生成: `kanabi2-dev/build-facility-dictionary.py`）
- 地図: Leaflet（同梱）+ OpenStreetMap

## サービス

- 既定のサービスURL: `https://sedate-landmark-shrunk.ngrok-free.dev`
  （設定タブで変更可能。IC選択フローの完全動作には B3 形式の
  サービスが要る。本番サービスへの B3 反映は別途待ち）
- マイルート / 設定タブは準備中のプレースホルダ（設定はサービスURLのみ実働）
